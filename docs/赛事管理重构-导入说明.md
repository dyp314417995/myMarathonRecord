# 赛事管理重构 + 表格数据导入说明

## 一、重构内容（按表格字段）

### 新数据模型字段（race_events）

| 分组 | 字段 | 来源 |
|---|---|---|
| 基础 | name(带年份) / raceGroup(不带年份) / date / province / city | 表格: 赛事、比赛日期、省份 |
| 项目等级 | raceTypes(full/half/10k) / raceLevel(A/B/C) / label(白金标/金标/精英标/普通标) | 表格: 比赛项目、赛事等级 |
| 规模费用 | scale(总规模) / subScale(分项规模) / fee | 表格: 总规模、分项规模、报名费 |
| 组织联系 | organizer(主办) / operator(运营) / contactPhone / contactEmail / wechatAccount / website | 表格: 主办单位、运营单位、联系电话、官方邮箱、微信公众号、官网 |
| 报名 | mechanism(抽签/先到先得) / payment / signupChannels(报名渠道) | 表格: 抽签、报名渠道 |
| 参赛要求 | medicalReport(体检报告) / finishRequirement(完赛经历) / refundRule(退出机制) / startPoint(起点) | 表格: 对应列 |
| 图片 | medalImage(奖牌) / routeMap(路线图) / posters | 表格: 奖牌、比赛路线(URL) |
| 报名状态 | regStatus(待确定/报名中/待开赛/待出签/待报名/已结束/取消) | 表格: 状态 |
| 时间线 | timeline(报名开启/报名截止/出签时间/缴费截止/鸣枪开跑) + gunTimes | 表格: 各时间列 |
| 系统 | status / publishStatus / source / createTime / updateTime | 系统 |

> 忽略：创建时间、最后编辑时间（表格列）；distance/elevation/certs/tags 表单不再展示（旧数据兼容保留）

## 二、数据来源与更新流程（v2.6 最终版）

> 数据源：腾讯在线文档《国内路跑认证赛事》
> https://docs.qq.com/smartsheet/DQlZpdE1QRFhST0dF?tab=sc_fJm8EC

### 首次全量初始化

1. 拉取：`node 赛事数据/update_saishi.js`（首次无快照 → 全量拉取并生成 5 个 CSV）
2. 转换：`node 赛事数据/csv-to-races.js` → 生成 `赛事数据/races_import.json`
3. 部署云函数：把 `cloudfunctions/importRaceSheet` 上传到云环境
4. 上传数据：把 `races_import.json` 上传到云存储，记下 fileID（如 `cloud://env.xxx/races_import.json`）
5. 试运行（不写库）：`cloud functions invoke importRaceSheet --params '{"storageFileID":"cloud://...","dryRun":true}'`
6. 正式导入：去掉 dryRun 再执行一次
7. 到小程序「赛事管理 → 草稿」页签审核发布

### 后续增量更新

1. `node 赛事数据/update_saishi.js`：查 rev 版本号，无变化直接退出；有变化全量重拉 + 记录级 diff（新增/修改/删除）+ 重新生成 CSV
2. `node 赛事数据/csv-to-races.js`：重新生成 `races_import.json`
3. 上传新 JSON 到云存储覆盖旧文件，再次调用 `importRaceSheet`
4. 增量规则（方案B：字段级保护）：
   - 无同名 → **直接新建 published**（信任表格，不再有草稿）
   - 同名且 `source='manual'`（人工创建）→ 跳过，不覆盖
   - 同名表格赛事 → **字段合并**：表格有值才覆盖；`manualFields` 里的人工修改字段保留
5. 管理端编辑赛事时，改动的字段自动记入 `manualFields`，下次导入保留你的修改，其余字段跟随表格更新
6. 存量草稿可用 `getRaceEvents` 的 `publishAllDrafts` action 一次性全部转已发布

> CSV 导出已排除「创建时间」「最后编辑时间」两列（需求 v2.6）

> 索引建议：race_events 增加 `{ name: 1 }` 索引（去重查询用）

## 三、说明

- 导入源标识 `source=table`，草稿卡片来源显示「国内路跑认证赛事」
- 同名（带年份）已发布赛事不会被覆盖，草稿会全量更新
- 无比赛日期的赛事（多为 2026/2025「待确定」）暂未导入，可在表格补日期后重新转换导入
