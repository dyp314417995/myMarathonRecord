# 赛事管理重构 + 表格数据导入说明

## 一、重构内容（按表格字段）

### 新数据模型字段（race_events）

| 分组 | 字段 | 来源 |
|---|---|---|
| 基础 | name(带年份) / raceGroup(不带年份) / date / province / city | 表格: 赛事、比赛日期、省份 |
| 项目等级 | raceTypes(full/half/10k) / raceLevel(A/B/C) / label(白金标/金标/精英标/普通标) | 表格: 比赛项目、赛事等级 |
| 规模费用 | scale(总规模) / subScale(分项规模) / fee | 表格: 总规模、分项规模、报名费 |
| 组织联系 | organizer(主办) / operator(运营) / contactPhone / contactEmail / wechatAccount / website | 表格: 主办单位、运营单位、联系电话、官方邮箱、微信公众号、官网 |
| 报名 | mechanism(抽签/先到先得) / payment / signupChannels(报名渠道) | 表格: 抽签、报名渠道 |
| 参赛要求 | medicalReport(体检报告) / finishRequirement(完赛经历) / refundRule(退出机制) / startPoint(起点) | 表格: 对应列 |
| 图片 | medalImage(奖牌) / routeMap(路线图) / posters | 表格: 奖牌、比赛路线(URL) |
| 报名状态 | regStatus(待确定/报名中/待开赛/待出签/待报名/已结束/取消) | 表格: 状态 |
| 时间线 | timeline(报名开启/报名截止/出签时间/缴费截止/鸣枪开跑) + gunTimes | 表格: 各时间列 |
| 系统 | status / publishStatus / source / createTime / updateTime | 系统 |

> 忽略：创建时间、最后编辑时间（表格列）；distance/elevation/certs/tags 表单不再展示（旧数据兼容保留）

## 二、导入步骤

1. 转换：`node 赛事数据/csv-to-races.js` → 生成 `赛事数据/races_import.json`（1030 条，含日期；134 条无日期未导出）
2. 部署云函数：把 `cloudfunctions/importRaceSheet` 上传到云环境
3. 上传数据：把 `races_import.json` 上传到云存储，记下 fileID（如 `cloud://env.xxx/races_import.json`）
4. 试运行（不写库）：`cloud functions invoke importRaceSheet --params '{"storageFileID":"cloud://...","dryRun":true}'`
5. 正式导入：去掉 dryRun 再执行一次
6. 到小程序「赛事管理 → 草稿」页签审核发布

> 索引建议：race_events 增加 `{ name: 1 }` 索引（去重查询用）

## 三、说明

- 导入源标识 `source=table`，草稿卡片来源显示「国内路跑认证赛事」
- 同名（带年份）已发布赛事不会被覆盖，草稿会全量更新
- 无比赛日期的赛事（多为 2026/2025「待确定」）暂未导入，可在表格补日期后重新转换导入
