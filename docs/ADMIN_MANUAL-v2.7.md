## 一、管理员按省份分配（v2.7）

### 配置入口

首页 → 管理 → **管理员配置**

### 添加 / 编辑

- "负责省份"为多选，**同一省可被多个管理员同时负责**（无唯一性）
- 选择省份后，列表卡片下方会显示省份 chip；不选则默认"全国"
- 提交时如有原记录会被自动撤销，再写入新记录

### 列表展示规则

- 仅 `status='active'` 且在有效期内的管理员在列表展示
- `revoked`（已撤销）的管理员**不在列表显示**（V2.7 起生效）

### 权限生效

普通管理员进入"赛事管理"页时，**默认只看自己负责省的赛事**（云函数侧 `adminProvinces` 过滤）。超管默认看全部，可手动切换。

## 二、赛事群二维码（v2.7 核心）

### 上传/更新

1. 赛事管理 → 找到目标赛事 → ✏️ 进入编辑
2. 在表单底部找到「群二维码」区块
3. 点击「上传二维码」选图（相册/拍照均可）→ 自动上传到云存储 + 写入 `qrCodeUpdatedAt`
4. 「清除」按钮可清空二维码（不视为过期，仅视为"未上传"）

> **任何** `provinces` 含赛事所在省的 active 管理员都能上传/更新——不限于"唯一负责人"。

### 列表筛选

| 筛选 | 含义 |
|------|------|
| 📱 全部二维码 | 不过滤 |
| 📱 无二维码 | `qrCode` 为空/不存在 |
| 📱 失效 | `qrCodeUpdatedAt` 距今 ≥ 7 天 |

典型工作流：
- 日常检查 → 选「失效」→ 找到自己负责的失效赛事 → 进入编辑 → 重新上传

### 列表卡片新增字段

- 「👤 负责人」tag：按 province 反查 admins 得到的负责人列表（多个用"、"分隔）
- 「📱 二维码状态」tag：今日上传 / N 天前上传 / 已过期 N 天 / 无二维码

## 三、二维码通知闭环

### 被动接收（你是负责人）

- **客户端用户主动通知**：用户点击赛事详情页「🔔 通知负责人处理」→ 你会收到微信订阅消息
- **每天 10:00 自动通知**：云函数扫描所有失效/缺失二维码 → 按省合并推送给你

> 文案示例：`北京 缺3个/过期5个群二维码`

点击通知 → 跳转到赛事管理页并自动定位到对应省份。

### 主动响应流程

1. 收到通知后，进入「赛事管理」页
2. 筛选条选「📱 失效」或「📱 无二维码」
3. 进入对应赛事编辑 → 重新上传群二维码
4. 客户端/下次定时扫描时即恢复正常

## 四、撤销管理员

- 列表中点「撤销管理员」→ 确认 → 该用户立即失去管理员权限
- 撤销后**从列表消失**（V2.7 起），不再保留"已撤销"灰显
- 历史记录保留在 `admins` 集合（`status='revoked'`），便于审计

## 五、常见问题

**Q：为什么我看不到某些赛事？**
A：超管才会看到所有赛事。普通管理员只能看到自己负责省的赛事；如需调整负责省份，联系超管重新分配。

**Q：上传了二维码，但客户端还是看不到？**
A：客户端不展示群二维码（避免被爬），仅做通知反馈。如需测试，到赛事详情页看是否还会显示「⚠️ 群二维码已过期」卡片。

**Q：多个管理员都能上传同一赛事的二维码吗？**
A：可以。最后上传的会覆盖之前的，`qrCodeUpdatedAt` 也会刷新。

**Q：二维码过期了系统会自动通知吗？**
A：是的。每天 10:00 云函数自动扫描全量失效/缺失赛事，按省合并通知负责人。

**Q：用户反映二维码过期了，但我没收到通知？**
A：检查（1）你是否有负责该赛事所在省；（2）订阅消息是否在订阅中心开启；（3）云函数 `raceQrExpireNotify` 当天是否成功跑（控制台 → 云函数 → 运行日志）。
