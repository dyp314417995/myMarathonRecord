# PRD 产品需求文档 v2.2 — 活动广场 + 赛事日历增强

> 版本：V2.2 | 状态：开发完成 | 模块：活动管理 + 活动广场 + 赛事日历

---

## 1. 概述

管理员可发布线下/线上活动，用户报名参与。活动完成后自动获得积分。

---

## 2. 管理员端 — 活动管理

### 2.1 入口
首页 → 管理 → 活动管理

### 2.2 发布活动

| 字段 | 类型 | 必填 | 说明 |
|------|------|:---:|------|
| 活动名称 | 文本 | ✅ | |
| 活动时间 | 日期+时间 | ✅ | 支持多天（开始-结束） |
| 活动地点 | 文本 | ✅ | |
| 费用 | 文本 | | 如"免费""AA制 50元" |
| 报名截止时间 | 日期+时间 | ✅ | |
| 人数上限 | 数字 | | 不填=不限 |
| 活动图片 | 图片 | | 最多 3 张 |
| 活动说明 | 富文本 | | 图文混排 |

### 2.3 自定义扩展表单

管理员可自行添加额外报名字段：

| 字段属性 | 选项 |
|----------|------|
| 类型 | 文本 / 单选 / 多选 / 数字 |
| 标题 | 如"衣服尺码""是否团餐" |
| 必填 | 是/否 |
| 选项 | 单选/多选时填写，逗号分隔 |

示例：
- 衣服尺码（单选）：S, M, L, XL, XXL
- 是否团餐（单选）：是, 否
- 备注需求（文本）

### 2.4 活动列表

管理端活动列表展示：
- 活动名称、时间、地点
- 报名人数 / 上限
- 操作：编辑、查看报名、取消活动、删除
- 取消后所有报名自动取消，不发放积分

### 2.5 查看报名详情

点击"查看报名"弹窗/跳转：
- 报名人员列表（头像、昵称、手机号）
- 自定义字段的填写内容（如表）
- 支持导出（可选）

---

## 3. 用户端 — 活动广场

### 3.1 入口
首页 → 小工具 → 活动广场

### 3.2 Tab 结构

| Tab | 说明 |
|-----|------|
| 所有活动 | 展示未过期的全部活动，按时间从近到远 |
| 我的活动 | 已报名的活动，按时间从近到远 |

### 3.3 活动卡片

每个卡片展示：
- 活动名称
- 活动时间（开始时间）
- 地点
- 报名人数 / 上限
- 费用（若有）

### 3.4 活动详情

点击卡片进入详情页：
- 活动全部信息（时间/地点/费用/说明/图片）
- **报名按钮**（未截止且未满员时）
- 自定义表单字段（报名时填写）

### 3.5 报名流程

1. 点击"立即报名"
2. 填写自定义字段
3. 确认提交
4. 该活动进入"我的活动"

### 3.6 取消报名

"我的活动"中可取消报名，截止时间前可操作。

### 3.7 积分奖励（自动）

参考「集体活动」积分规则。活动结束后：

- 管理员可选择"活动已完成"
- 系统自动给所有报名用户 +3 积分
- 积分规则走现有 `集体活动` 分类（`points: 3`）

## 4. 数据模型

### 4.3 分页统一
- 赛事日历、活动广场、活动管理、赛事管理全面改用服务端分页（skip/limit）
- 每页 20 条，拉到底"加载更多"
- 云函数 getActivities / getRaceEvents 返回 total + hasMore

```js
{
  _id: String,
  name: String,           // 活动名称
  timeStart: Date,        // 开始时间
  timeEnd: Date,          // 结束时间
  location: String,       // 地点
  fee: String,            // 费用
  deadline: Date,         // 报名截止时间
  maxPeople: Number,      // 人数上限（null=不限）
  images: [String],       // 活动图片 fileID
  description: String,    // 活动说明
  qrcode: String,         // 小程序码 cloud fileID
  customFields: [{        // 自定义字段（上限5个）
    key: String,          // 字段标识
    label: String,        // 字段标题
    type: 'text'|'radio'|'checkbox'|'number',
    required: Boolean,
    options: [String],    // 单选/多选的选项
  }],
  status: 'active'|'finished'|'cancelled',
  creatorId: String,      // 管理员 openId
  createTime: Date,
}
```

### 4.2 `activity_registrations` 集合

```js
{
  _id: String,
  activityId: String,     // 关联活动
  userId: String,         // 用户 _id
  userName: String,       // 冗余：用户昵称
  userPhone: String,      // 冗余：手机号
  customValues: {         // 自定义字段值
    "size": "L",
    "dinner": "是",
  },
  status: 'active'|'cancelled',
  createTime: Date,
}
```

活动标记完成后，遍历 `activity_registrations` 中 `status='active'` 的记录，调用 `pointsUtil.addRecord()`：

  points: 3,
  description: `参加活动：${activityName}`,
}

## 8. 实现要点

### 赛事倒计时优化
- 优先查找最近的下一个时间节点（报名截止/出签/鸣枪开跑等）
- 有发枪时间也参与时间节点比较
- 标签去"时间"后缀（出签时间→出签）
- 统一使用"鸣枪开跑"，不再用"开赛"

### 状态流转
| 条件 | 状态 |
|------|------|
| `status=cancelled` | 已取消 |
| `status=finished` | 已完成 |
| 满员 | 已满员 |
| 截止时间过 | 已截止 |
| 结束时间过 | 已结束 |
| 开始时间过 | 进行中 |
| 其他 | 报名中 |

- 结束时间过后自动变为「已完成」并发放积分（3 分/人，集体活动规则）
- 状态由云函数 `computeState` 统一计算，管理端和用户端完全同步

### 分享二维码
- `genActivityQR` 云函数：`wxacode.getUnlimited` 生成小程序码
- 扫码带 `scene=act=xxx`，`app.js` 解析跳转
- 未注册用户先注册后直达报名页

### 时间默认值
- 开始时间默认 7:00，结束 +2h，截止 -1h
- 改开始时间自动同步结束和截止

### 自定义字段
- 支持文本、单选、多选三种类型
- 选项逗号分隔

### 数据集合
- `activities`：活动主表
- `activity_registrations`：报名记录

### 云函数
- `getActivities`：CRUD + 报名 + 积分发放 + 状态计算
- `genActivityQR`：小程序码生成
- `getImageUrls`：批量转换 cloud:// fileID 为临时 URL（配置了 CDN 加速）

## 9. 赛事日历增强（v2.2）

### 9.1 多赛事图片

**管理端（赛事管理）：**
- 支持上传最多 9 张赛事图片，取代旧版单张海报
- 上传后自动上传至云存储，保存 fileID 到 `race_events.posters` 数组
- 网格展示：1 张占单列，2 张占 2 列，3 张以上占 3 列
- 每张缩略图右上角 ✕ 可单独删除
- 支持排序：点击「调整顺序」进入排序模式，左右箭头调整位置
- 编辑时已上传图片回显（cloud:// 转临时 URL）

**用户端（赛事详情）：**
- 朋友圈式网格展示，自适应列数（1/2/3 列）
- 点击图片全屏预览，左右滑动切换，顶部显示序号（1/9）
- 点击 ✕ 关闭预览

### 9.2 规模/费用按类型展示

混合赛事（全马+半马）时，规模和费用分别按类型展示：

| 字段 | 展示方式 |
|------|---------|
| 规模 | `全马 3000人 · 半马 5000人` |
| 费用 | `全马 200元 · 半马 150元` |
| 机制 | 抽签 · 先缴费 |

仅单类型时直接展示对应字段值。未录入的字段不展示。

### 9.3 官网链接优化

- 详情页展示官网链接，点击复制到剪贴板
- 复制后弹窗显示链接内容，提示用户到浏览器打开
- 避免直接使用 web-view（域名不固定）

### 9.4 元信息布局优化

- 每行采用 `label: value` 格式，视觉对齐
- 仅有值的字段才展示，避免空行浪费空间
- 字段：城市·类型·等级·标签 / 距离·爬升 / 认证 / 规模 / 费用·机制·支付 / 官网

### 9.5 二维码跳转修复

- 修复 `app.js` `checkLaunchScene` 中活动码和赛事码相互冲突的问题
- 通过 `launchOptions.path` 判断扫码落地页面，区分活动（`pages/tools/activity/detail`）和赛事（`pages/tools/calendar/detail`）
- 活动未登录时保留 `pendingActivityId`，注册后自动跳转
- 赛事无需登录即可查看，不做 pending 跳转

### 9.6 标记状态展示

- 赛事详情页始终展示标记状态：
  - 已标记：显示当前状态（已报名/已完赛等）+「修改」按钮
  - 未标记：显示「🏷 标记我的赛事」按钮
- 评分按钮根据状态联动：
  - 已评价：显示「✏️ 修改评价」
  - 已完赛未评价：显示「⭐ 参与评分」
  - 已标记未完赛：显示禁用状态「需标记已完赛后才可评分」

### 9.7 数据模型变更

#### `race_events` 集合

```js
{
  // ...原有字段
  poster: String,         // 旧版单图（兼容保留）
  posters: [String],      // 新版多图 cloud fileID 数组（新增）
}
```
