# PRD 产品需求文档 v2.5 — 小工具：跑步账本

> 版本：V2.5 | 状态：迭代五 | 模块：跑步账本（收支记账）

---

## 1. 概述

新增「跑步账本」小工具，供跑者记录跑步相关的收支：

- **记账先选类型**：支出（默认）/ 收入，二者互斥
- **支出** 分两大类：日常开支 / 比赛开支，各带小类；比赛开支可关联具体赛事
- **收入** 不分大类小类，内置收入类型（比赛奖金等）
- 每一笔可**附图最多 3 张**（拍照/相册，可删除、预览）
- 账单支持**按月 / 按年 / 自定义时间段**汇总，以及**按大类、小类（多选）**查询

---

## 2. 记账规则

### 2.1 类型（互斥，默认支出）

| 类型 | 说明 |
|------|------|
| 支出 | 默认；需选大类 → 小类；比赛开支可再选赛事 |
| 收入 | 不分大类小类；只需选收入类型 |

### 2.2 支出大类与小类

| 大类 | 小类 |
|------|------|
| 日常开支 | 跑鞋、衣服、买补给、手表、耳机、眼镜、其他（自定义） |
| 比赛开支 | 补给品、吃喝、纪念品、报名费、交通、住宿、旅行、钞能力名额、其他（自定义） |

> 「其他」选中后出现自定义输入框，自定义文本直接作为小类存储，并自动出现在筛选选项里。

### 2.3 比赛开支：赛事关联

| 场景 | 处理 |
|------|------|
| 已标记赛事 | 下拉默认列出「我的赛事」（已标记，按日期倒序） |
| 想补标记 | 表单内提供「🏁 去我的赛事补充标记 ›」快捷入口，跳转赛事日历「我的赛事」页；返回后自动刷新赛事列表 |
| 未收录的小赛事 | 选择「自定义赛事…」手动输入赛事名 |

### 2.4 收入类型

| 类型 | 说明 |
|------|------|
| 比赛奖金 | 内置，默认 |
| 其他 | 自定义输入（如：赞助、退款） |

### 2.5 通用字段

金额（元，两位小数）、日期（默认今天）、备注（≤200 字）、附图（≤3 张，`cloud://` fileID）。

---

## 3. 查询与汇总（账本首页）

| 维度 | 能力 |
|------|------|
| 时间 | 本月 / 本年 / 自定义时间段（起止日期选择） |
| 类型 | 支出 / 收入**互斥页签**，默认支出；选收入时顶部汇总卡切换为橙色并显示收入总额 |
| 分类（仅支出） | 大类**多选**；点击大类**展开小类**（小类**多选**，不选=该大类全部）；小类含自定义 |
| 汇总卡 | 支出总额 + 日常/比赛拆分；收入总额；笔数 |
| 列表 | 按日期分组，当日小计 = 收支净额（收入 +、支出 -） |
| 展示 | 收入 `+¥` 绿色 +「收入」标签；支出 `-¥` 红色 |

## 4. 数据模型 `ledger`

```js
{
  _id: String,
  userId: String,          // 云函数写入，OPENID 隔离
  entryType: String,       // 'expense' | 'income'
  bigCategory: String,     // 支出：'daily' | 'race'
  smallCategory: String,   // 支出小类（自定义存实际文本）
  eventName: String,       // 比赛开支关联赛事名（可选）
  eventId: String,         // 赛事 _id（可选，自定义赛事为空）
  incomeType: String,      // 收入类型（如：比赛奖金）
  amount: Number,          // 金额（元，2 位小数）
  date: String,            // 'YYYY-MM-DD'
  note: String,            // 备注
  images: Array,           // cloud:// fileID，≤3
  createTime: Date,
  updateTime: Date,
}
```

> 兼容：老数据无 `entryType` 字段一律视为支出。
> 集合由云函数 `ensureCollection` 自动创建，无需手动建库。

## 5. 接口设计（云函数 `ledger`）

| action | 入参 | 说明 |
|--------|------|------|
| `list` | `page` / `pageSize` / `startDate` / `endDate` / `entryType` / `bigs` / `smalls` | 列表 + 汇总（支出/日常/比赛/收入）+ 分页 + 图片临时链接 + 可用小类（按大类） |
| `add` | `entryType`；收入：`incomeType`；支出：`bigCategory` / `smallCategory` / `eventName` / `eventId`；通用：`amount` / `date` / `note` / `images` | 新增 |
| `update` | `id` + 同 add 字段 | 编辑；切换类型时清理另一类型字段 |
| `remove` | `id` | 删除（仅本人） |
| `detail` | `id` | 详情（含图片临时链接） |
| `myRaces` | `userId`（兜底） | 我的赛事（已标记）列表，供比赛开支选择 |

- 所有 action 通过 `cloud.getWXContext().OPENID` 定位用户；`myRaces` 兼容客户端传内部 `_id` 兜底（个别用户 `_openid` 反查失败时）
- 每次调用前 `ensureCollection()` 自动创建 `ledger` 集合

## 8. 异常场景

| 场景 | 处理 |
|------|------|
| 首次进入集合不存在 | 云函数 `ensureCollection` 自动创建，不报错 |
| 老记录无 `entryType` | 一律视为支出 |
| 编辑时切换支出/收入 | 更新时清空另一类型字段（bigCategory/smallCategory/eventName/eventId ↔ incomeType） |
| 收入选「其他」未输入 | 保存为「其他」 |
| 自定义小类 | 以小类文本直接存储，自动出现在筛选 chips（按大类归集） |
| 云函数未部署（旧版） | 客户端兜底显示「不选/自定义」，并 toast 提示，仍可先记账 |
| 图片上传中途失败 | 已上传的图保留，提示重试，不阻塞保存（图非必填） |
