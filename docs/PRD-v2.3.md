# PRD 产品需求文档 v2.3 — 积分规则可配置化

> 版本：V2.3 | 状态：迭代三 | 模块：积分规则管理 + 提交次数校验

---

## 1. 概述

将积分规则从「仅超管可启用/禁用」升级为「超管可完全配置」：
- 支持新增 / 删除 / 修改积分规则（规则名称、分类、积分值、启用状态）
- 支持配置提交上限：提交周期（日 / 周 / 月）+ 次数限制（1~10）
- 用户提交积分申请时，按自然周期校验是否已达上限，超限拦截

---

## 2. 积分规则管理（超管）

### 2.1 入口
积分管理 → 规则 Tab（仅 `super_admin` 可见管理操作）

### 2.2 规则列表
每条规则卡片展示：
- 规则名称
- 积分值（`+N 分`）
- 限制文案（如「每周最多 2 次」「每月最多 4 次」；不限则不展示）
- 状态：已启用 / 已禁用

### 2.3 操作

| 操作 | 说明 |
|------|------|
| 新增规则 | 点击「+ 新增规则」弹出表单 |
| 编辑规则 | 点击「编辑」，回填表单 |
| 删除规则 | 点击「删除」，二次确认后删除 |
| 启用/禁用 | 点击状态标签切换 `active` / `disabled` |

### 2.4 规则表单

| 字段 | 类型 | 必填 | 说明 |
|------|------|:---:|------|
| 规则名称 | 文本 | ✅ | 如：邀请跑友加入 |
| 分类名称 | 文本 | ✅ | 提交申请时按分类选择；同一分类不允许重复 |
| 积分值 | 正整数 | ✅ | |
| 提交周期 | 单选 | | 不限制 / 每天 / 每周 / 每月 |
| 次数限制 | 1~10 | 周期非空时 | 如：每月 4 次、每周 1 次 |
| 状态 | 单选 | | 启用 / 禁用 |

> 规则初始化策略变更：`initDefaultRules` 只补缺失分类，**不再覆盖已有规则**，避免超管自定义被重置。

## 3. 用户提交校验（周期 + 次数）

### 3.1 校验规则
- 用户选择分类后，读取该规则配置的 `period` + `limitCount`
- 统计当前自然周期内该用户该分类的已提交次数（`pending` + `approved`，即待审核 + 已通过）
- 已达上限（`used >= limit`）时禁止提交，并提示「本周/本月/今天已达上限，无法提交」

### 3.2 自然周期定义

| 周期 | 起止 |
|------|------|
| 日 | 当天 00:00 ~ 次日 00:00 |
| 周 | 自然周，**周一 00:00 ~ 下周一 00:00** |
| 月 | 自然月，**1 号 00:00 ~ 次月 1 号 00:00** |

### 3.3 前端展示
- 分类卡片显示限制文案，如 `+3分(每月最多4次)`
- 选中分类后显示 `本周已提交 1/2 次`
- 达上限显示红色提示 `本周已达上限，无法提交`，提交按钮仍可点击但会被拦截

## 4. 数据模型 — `points_rules` 集合

```js
{
  _id: String,
  name: String,          // 规则名称
  category: String,      // 分类名称（唯一）
  points: Number,        // 积分值
  period: '' | 'day' | 'week' | 'month',  // 提交周期，空=不限
  limitCount: Number,    // 次数限制 1~10（period 为空时为 0）
  status: 'active' | 'disabled',
  createTime: Date,
  updateTime: Date,
}
```

**兼容旧数据**：旧规则仅含 `monthlyLimit` 字段，读取时自动映射为 `period='month', limitCount=monthlyLimit`。
