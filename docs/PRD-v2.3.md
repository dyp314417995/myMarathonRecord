# PRD 产品需求文档 v2.3 — 积分规则可配置化

> 版本：V2.3 | 状态：迭代三 | 模块：积分规则管理 + 提交次数校验

---

## 1. 概述

将积分规则从「仅超管可启用/禁用」升级为「超管可完全配置」：
- 支持新增 / 删除 / 修改积分规则（规则名称、描述、积分值、启用状态）
- 移除「分类名称」：规则以「规则名称」为唯一标识；三个固定自动发放类型（注册赠送 / 集体活动 / 赛事评分奖励）按规则名称取值
- 规则可配置「是否需要用户提交」与「单次可提交数量」
- 用户提交积分申请时，按自然周期校验是否已达上限，超限拦截

---

## 2. 积分规则管理（超管）

### 2.1 入口
积分管理 → 规则 Tab（仅 `super_admin` 可见管理操作）

### 2.2 规则列表
每条规则卡片展示：
- 规则名称
- 积分值（`+N 分`）
- 限制文案（如「每周最多 2 次」「每月最多 4 次」；不限则不展示）
- 提交方式标签：用户可提交 / 无需提交（自动发放、管理员录入）
- 状态：已启用 / 已禁用

### 2.3 操作

| 操作 | 说明 |
|------|------|
| 新增规则 | 点击「+ 新增规则」弹出表单 |
| 编辑规则 | 点击「编辑」，回填表单 |
| 删除规则 | 点击「删除」，二次确认后删除（软删除，刷新后不会重新生成默认规则） |
| 启用/禁用 | 点击状态标签切换 `active` / `disabled` |

### 2.4 规则表单

| 字段 | 类型 | 必填 | 说明 |
|------|------|:---:|------|
| 规则名称 | 文本 | ✅ | 如：邀请跑友加入；三个固定自动发放类型必须命名为「注册赠送 / 集体活动 / 赛事评分奖励」 |
| 规则描述 | 多行文本 | | 详细阐述规则（≤50字）；管理员和普通用户点击规则名称可查看 |
| 是否需要用户提交 | 单选 | | 需要（展示在申请页）/ 不需要（自动发放、管理员录入） |
| 积分值 | 正整数 | ✅ | |
| 单次可提交数量 | 正整数 | | 默认 1；仅「需要用户提交」时展示；>1 时申请页显示数量选择，积分按数量累计（范围 1~100） |
| 注册赠送随机范围 | 最小值~最大值 | | 仅规则名称为「注册赠送」时展示；填写后注册赠送在该区间随机取值（抢红包效果） |
| 提交周期 | 单选 | | 仅「需要用户提交」时展示；不限制 / 每天 / 每周 / 每月 |
| 次数限制 | 1~10 | 需要用户提交且周期非空 | 如：每月 4 次、每周 1 次 |
| 状态 | 单选 | | 启用 / 禁用 |

> 规则不再自动生成：积分规则**全部由超管手工配置**，系统不会创建或补建任何默认规则（删除后不会自动恢复）。
> 兜底行为：三个固定自动发放类型（注册赠送 / 集体活动 / 赛事评分奖励）被**禁用或删除**后，对应发放仍按兜底积分执行（50 / 3 / 10），**不会自动停发**。
> 固定名称保护：三个固定类型**请勿改名**，否则对应发放将按兜底值执行（表单中已有提示）。

### 2.5 规则查看（管理员 / 普通用户）
- 管理员和普通用户**不可编辑 / 配置规则**，仅可查看
- 积分首页展示规则**名称列表**（含积分值），点击规则名称弹窗显示**规则描述**

## 3. 用户提交校验（周期 + 次数）

### 3.1 校验规则
- 用户选择规则后，读取该规则配置的 `period` + `limitCount`
- 统计当前自然周期内该用户该规则（按规则名称）的已提交次数（`pending` + `approved`，即待审核 + 已通过）
- 校验时**本次提交数量也计入上限**：`used + quantity > limit` 时禁止提交，并提示「本周/本月/今天已达上限（本次提交 N 次将超限），无法提交」

### 3.2 自然周期定义

| 周期 | 起止 |
|------|------|
| 日 | 当天 00:00 ~ 次日 00:00 |
| 周 | 自然周，**周一 00:00 ~ 下周一 00:00** |
| 月 | 自然月，**1 号 00:00 ~ 次月 1 号 00:00** |

### 3.3 前端展示
- 规则卡片显示限制文案，如 `+3分(每月最多4次)`
- 选中规则后显示 `本周已提交 1/2 次`
- 达上限显示红色提示 `本周已达上限，无法提交`，提交按钮仍可点击但会被拦截

## 4. 数据模型 — `points_rules` 集合

```js
{
  _id: String,
  name: String,          // 规则名称（唯一；三个固定自动发放类型：注册赠送/集体活动/赛事评分奖励）
  description: String,   // 规则描述（详细阐述，用户点击规则名查看）
  points: Number,        // 积分值
  maxQty: Number,        // 单次可提交数量（默认1，>1时申请页可选数量）
  minPoints: Number,     // 注册赠送随机最小值
  maxPoints: Number,     // 注册赠送随机最大值
  period: '' | 'day' | 'week' | 'month',  // 提交周期，空=不限
  limitCount: Number,    // 次数限制 1~10（period 为空时为 0）
  needSubmit: Boolean,   // 是否需要用户提交：false=自动发放/管理员录入，不出现在申请页
  status: 'active' | 'disabled' | 'deleted',  // deleted=软删除
  createTime: Date,
  updateTime: Date,
}
```

**兼容旧数据**：旧规则仅含 `monthlyLimit` 字段，读取时自动映射为 `period='month', limitCount=monthlyLimit`；`migrateRules` 迁移移除旧 `category` 字段，并将三个固定自动发放类型的旧分类值补为规则名称。
