## 2026-10-28　荣耀时刻与跑马记录合并

大家好，这次把「我的荣耀时刻」和「跑马记录」合成一份数据了：

1. **证书、名次直接在跑马记录里填**（完赛证书最多 3 张），荣耀墙自动出现，不用录两遍。
2. **只有传了证书的才上墙**，只录成绩的仍留在跑马记录里，能看成绩、能算 PB。
3. **顶部可按项目切换**（全部 / 全马 / 半马 / 10 公里 / 其他），每项带场次；右边 ⚙️ 可设默认展示哪个，主跑什么就设什么。分享出去的也是当前项目，标题场次跟着变。
4. **每个项目的 PB 那场，卡片右上角标 🏆 PB**（按成绩自动算）。
5. **添加、编辑、删除统一在跑马记录里做**，荣耀页点「编辑」会直接打开那条记录的表单，免得在墙上误删整条成绩。
6. 顺手修的几处：设置弹窗点不开、手机上点编辑跳不过去、灰色提示文字点不动、跑马记录顶部「成绩变化」没按时间倒序。

## 2026-10-28　冬训打卡与审核调整，新增我的证书

大家好，这次主要按大家实际用起来的情况，调整了打卡和审核，另外加了一个存证书的地方：

1. **打卡一天可以打多次**
   有人早晚各跑一趟，以前一天只能留一条（再提交会把上一条覆盖掉），现在一天可以打多次，每次最多上传 3 张截图。周统计照旧按跑量累加、天数按日期去重，算法没变。

2. **「待审」改成「审核」**
   审核页现在分「待审」「已审」两栏，组内所有人的打卡记录都在「已审」里看。「我的组」里那个重复的「去打卡」去掉了（首页九宫格本来就有）。

3. **管理组不再抽查审核**
   打卡一律由本组的队长/教练审核。

4. **可以请假了**
   「我的组」→ 请假 → 申请，填起止日期和原因（伤病 / 事假 / 参赛调整等），单次最长 7 天，队长审批通过后该周不考核：不计完成率、不产生罚金。榜单上会标出「请假」，首页也会提示本周请假中。

5. **新增「我的荣耀时刻」**
   「我的」页多了「我的荣耀」→ 我的荣耀时刻，按全马 / 半马 / 10 公里分区展示已完赛的每一场，组内按比赛时间倒序，顶部有各项目的场次统计。
   它的数据就是跑马记录里已完赛的那些，证书图片和名次直接挂在记录上，不用再单独录一遍 —— 在跑马记录里传了证书，荣耀墙就自动出现。想单独加一条也可以，从「我的赛事」选一场能带出赛事信息和已记录的成绩。支持转发给朋友和分享到朋友圈。

对应提交：`f0ee7d5`、`71c592f`

## 2026-10-27　补充更新

根据这两天实际用起来的情况，又补了三处：

1. **修复：编辑宣言 / 照片的入口看不清、保存按钮点不到**
   队长编辑宣言照片的入口之前是绿字配绿底，等于隐形，已改成白色按钮；后台弹窗内容太长时不能滚动、底部「保存」也点不到，现在可以滚动了。

2. **调组时可以指定角色**

3. **管理后台可以删除组别**
   组里有人的话会先提醒，删除后成员转为未分组，需要重新报名或由管理员调组。

## 2026-10-27　我的跑马记录 更新日记

大家好，根据最近大家提的意见，这次做了下面这些调整：

1. **S 组的专属安排**
   S 组本身有自己的训练计划和习惯，所以这次给了两项专属待遇：
   - 免费参加冬训营
   - 打卡无需审核，提交即通过。

2. **一个人可以带多个组**
   管理后台编辑组别时可以指派队长和教练，同一个人可以同时担任多个组的队长或教练，各组的审批、打卡审核权限都能用。

3. **队长可以自己维护队伍宣言和照片**
   「我的组」页面，队长可编辑，其他人可查看。

4. **跑马成绩按比赛时间排序**
   不再按录入先后，越早的比赛排在越上面。

5. **修复：周一没有重新计算本周进度**
   之前新的一周开始后，进度还跟上周的数据混在一起、显示 100%。现在每周一会重新计算本周的跑量和 KPI 完成情况。
