## 2026-10-30　跑友互助：修掉发布失败，几处规则也调顺了

大家好，根据最近大家用「跑友互助」时反馈的问题，改了这么几处：

1. **修复：发布互助、应征互助一直失败**

   点发布只弹一句「发布失败，请重试」，看着像没保存上，其实是申请消息通知那一步写法有问题——接口只要传了回调参数就不返回 Promise，代码却按 Promise 的写法链式往下接，当场报错，流程直接断在半路，连服务器都没走到，所以服务端也查不到任何异常。应征同样受影响，也是点不动。现在改成稳妥写法，就算没拿到通知授权也会继续往下走。顺带把截止时间的选择范围也收了口，避免选到最后一天反而提交失败。

2. **别人取消的，不再算在你头上**

   同一场赛事最多能撤销 3 次应征，这是防有人反复应征套取联系方式。但之前发起人取消发布把应征作废了，也会扣应征者的次数——等于他什么都没做，被别人连着撤三次就再也不能应征这场了。现在只统计自己主动退的那些。

3. **堵上「标记完成」绕过规则的口子**

   临近截止时取消发布是要算放鸽子的；但如果这时候改点「标记完成」，既能删掉，又不用通知任何人、也不用受罚。现在有人应征了又还没到截止的，只能走「取消发布」，该提醒的会提醒到位。已经标记完成的，也不给再取消了。

4. **取消之前把话说清楚**

   有人应征了再取消，弹窗会写明牵连几位跑友；临近截止还会把「这次会算放鸽子」说在你按下之前，不搞事后通知。

这块规则环环相扣，大家实际约起来遇到什么问题、或者觉得哪条别扭，随时跟我说，我接着调。

对应提交：`f54c03a`、`8994f52`

## 2026-10-28　冬训营调整 + 我的荣耀时刻

**冬训营**

- 打卡一天可以打多次，每次最多 3 张截图，周统计照旧按跑量累加、天数按日期去重。
- 审核页分「待审」「已审」两栏，组内所有人的打卡都能在「已审」里看。
- 打卡一律由本组的队长 / 教练审核。
- 可以请假：「我的组」→ 请假，填起止日期和原因（伤病 / 事假 / 参赛调整等），单次最长 7 天，队长通过后该周不考核 —— 不计完成率、不产生罚金，榜单上会标「请假」。

**我的荣耀时刻**（「我的」→ 我的荣耀）

- 和跑马记录是同一份数据：在跑马记录里填成绩、传完赛证书（最多 3 张）和名次，这里自动出现，不用录两遍。
- 只有传了证书的比赛才上墙，按全马 / 半马 / 10 公里分区，最新的排最上面。
- 每个项目最快的那一场，卡片右上角标 🏆 PB。
- ⚙️ 可以设置进来默认看哪个项目；也能分享给好友和朋友圈，分享出去的就是当前这个项目。

## 2026-10-27　我的跑马记录 更新日记

1. **S 组的专属安排**

   之前新的一周开始后，进度还跟上周的数据混在一起、显示 100%。现在每周一会重新计算本周的跑量和 KPI 完成情况。
